# BulkRename
Automatically rename files of any extension in bulk using Python.

For example:

Before:

```
cat.jpg
dog.jpg
mountain.jpg
```

After:

```
FileOrg_1.jpg
FileOrg_2.jpg
FileOrg_3.jpg
```

---

## ✨ Features

- Batch rename files
- Rename only a specific file extension
- Simple and beginner-friendly
- Lightweight (no external libraries required)

---

## 📚 Built With

- Python
- os module
